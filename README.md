# Zombie Jerky

Cook rotten flesh in a smoker to make edible **Zombie Jerky** — no more food poisoning from desperate zombie-flesh meals.

## Features

- Adds the `zombie_jerky` item to the Food & Drink creative tab.
- Smoker recipe: 1 rotten flesh → 1 zombie jerky (100 ticks, 0.1 XP).
- Nutrition 1, saturation 0.5, always edible, no negative effects.

## Requirements

- **Minecraft** 26.1.x
- **Fabric Loader** 0.18.4+ with **Fabric API** _or_ **NeoForge** 26.1+
- **Java** 25

## Building from source

```bash
./gradlew buildAll
```

Artifacts land in `fabric/build/libs/` and `neoforge/build/libs/`.

Run a dev client:

```bash
./gradlew :fabric:runClient
./gradlew :neoforge:runClient
```
